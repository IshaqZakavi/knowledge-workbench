# Keep decision context with work

Fictional worked example of a reusable insight.

An action is easier to reassess when the reason for it, the original evidence and
its scope limits remain linked. A task title alone can outlive the context that
made it appropriate.

Link work to its decision and source. Revisit the decision if the premise changes.
This is a useful design principle to test, not a measured universal benefit.
