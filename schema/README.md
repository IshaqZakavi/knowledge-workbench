# Frontmatter contract

`frontmatter.schema.json` is selected from the personal Python template. Its
project enumeration is replaced with a fictional workstream. Unknown metadata
must be omitted rather than fabricated. The sample validator also checks local
references, source mirroring, path boundaries and graph cycles.

The later TypeScript vault design uses a different envelope: stable IDs, slugs,
stages, domains, versions, sensitivity and share lists. That is an evolution of
the same project, not a claim that this schema validates both formats.
