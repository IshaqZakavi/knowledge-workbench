# Compose

Selected adaptation of the knowledge-work method for this public template.

Begin with the requested purpose, reader and decision. Gather curated records as the primary source; use atomic notes and references where they add value. An output can be composed without passing through the atomic layer.

Read the latest relevant updates and distinguish what was decided, what is still underway and what is unknown. Use sources to support factual statements. A clear recommendation can coexist with incomplete evidence.

Save authorized drafts to `work-products/` with `type: deliverable` and `status: draft`. In this public adaptation, use `origin` for direct derivation, `supporting` for additional evidence and `related` for wider context. Cite material claims inline. The original composition workflow used `related` for source lists too; this sample makes the distinction explicit.

Choose a structure that suits the question: decision needed, current position, rationale, unresolved issues and recommended next steps. Do not force every output into an executive report.

Review factual support, freshness, audience, confidentiality and ownership before preparing an outward-facing version. Writing a draft is not publishing it. `published/` records an explicit sharing boundary; this public template includes no export executor.
