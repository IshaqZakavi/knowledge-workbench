# Review before routing

## Context and forces

An assistant can find more possible actions than a person intends to accept.
Fast capture and deliberate commitment need different operations.

## Consequences

Review adds friction, but preserves the difference between an idea, an obligation
and completed work. The right gate depends on the consequence of the action.
