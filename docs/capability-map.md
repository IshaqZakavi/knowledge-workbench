TypeScript protocol and personal/work-specific vaults. This public selection
shows their shared method while keeping implementation claims separate.

authored contract or workflow, not an automated implementation. **Broader source**

## Three implementation distinctions that matter

**The Python template's current search is not this demo's RRF function.** The
inspected search path uses native LanceDB hybrid retrieval and optional
reranking. An older RRF helper exists but is not the active call path. This
public adapter uses a small rank-fusion implementation for inspectability.

**The later TypeScript graph is not NetworkX.** It uses a SQLite graph read layer.
Graph population, derived insight stores and experimental richer graph formats
have separate code paths and maturity. They should not be described as one
fully integrated production service.

**Instruction, implementation and measured outcome are different evidence.** A
skill can describe how to prepare a brief; code can expose source records; neither
proves time saved, accurate interpretation or comprehensive privacy enforcement.

The source review found substantive implemented components and thoughtful design,
not evidence for claiming that every planned connector and workflow is complete.
